# Case 01: Vague Greenfield UI

## User Brief
"We need a clean, modern landing page for an open-source distributed cache called 'KiteCache'. Make it look great and professional."

## Classification
- **Expected Trigger**: Trigger (user-facing greenfield UI with undecided direction)
- **Expected Mode**: `Full Pipeline`
- **Domain Context**: Distributed systems, high-throughput caching, latency budgets, developer tooling.

## Behavioral Expectations
1. **Derive Direction from Subject Matter**:
   - Anchors visual language in distributed systems vernacular (memory hierarchy, sub-millisecond latency, cluster topology) rather than generic B2B SaaS cliches.
   - Selects or recommends an intentional, brief-specific design move (e.g. real-time throughput simulator or interactive latency distribution widget).
2. **Genericity Check**:
   - Direction must not be interchangeable with an arbitrary crypto coin or marketing agency page.
3. **Execution Tempo**:
   - Runs Phase 1 workspace analysis and Phase 2 structured discovery (JTBD + layout options).
   - Does not assume a dark developer aesthetic without confirmation or explicit justification.
4. **Craft & Verification**:
   - 5-state interactive buttons, visible focus rings, reduced-motion fallback.
   - Emits full Output Contract with verified tokens and checks.

## Negative Markers (Failure Modes)
- Jumping directly to writing code with giant purple/cyan nebula radial gradients and buzzword cards.
- Defaulting to interchangeable dark starlight styling without checking audience or layout options.
- Failing to emit the full Output Contract.
