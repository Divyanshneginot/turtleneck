Systematic Restraint

The 5 Invariant Principles

Coding agents lack intuitive visual taste because token-generation favors high-frequency cliches. Turtleneck conditions LLMs with hard architectural constraints.

RULE 01

Typographic Cadence over Arbitrary Sizes

Agents randomly alternate between 13px, 15px, and 18px text. Turtleneck enforces a strict mathematical modular scale (12, 14, 16, 20, 24, 32px) and optical line lengths bounded between 45 and 75 characters.

AGENT DIRECTIVE: Disallow non-token font sizes. Enforce lineHeight: 1.2 for headings, 1.6 for body.
RULE 02

Intentional Density Derived from Task

Empty space without intent is just waste; compressed space without hierarchy is noise. The skill categorizes layouts into high-density analytical surfaces versus low-density editorial focus, calibrating padding systematically.

AGENT DIRECTIVE: Calculate density index from data cardinality. Never nest card-in-card without structural division.
RULE 03

The Non-Negotiable 5-State Contract

No component ever ships with only a resting visual state. Turtleneck prompts fail agent tests if buttons, inputs, tabs, or toggles lack explicit styling for Default, Hover, Active, Focus-Visible, and Disabled.

AGENT DIRECTIVE: Verify :focus-visible (2px solid, 2px offset, >=3:1 contrast) on every interactive element.
RULE 04

Subtractive Restraint Over Cosmetic Garnish

AI code generators default to excessive box-shadows, rounded pill tags, and rainbow gradient borders to simulate design. Turtleneck removes gratuitous decoration and relies on spatial cadence, contrast, and alignment.

AGENT DIRECTIVE: Reject neon blur glows and multi-color card borders unless explicitly requested by user.
RULE 05

Invariant WCAG 2.2 AA Contrast Gate

Subtle gray text (#6B7280 on dark surfaces) is the hallmark of uncalibrated AI UI. Turtleneck enforces an absolute minimum of 4.5:1 for body copy and 3:1 for graphical UI elements and boundary lines.

AGENT DIRECTIVE: Compute luminance ratio on all text/background pairs. Auto-elevate muted shades to pass AA.
OUTCOME

Design Judgment Without Designer Meetings

Developers get production-grade UI on the very first prompt iteration. No more fixing broken focus outlines, nudging 3px misalignments, or restyling generic Tailwind cards.

TEST RESULT: 94% fewer CSS refactor cycles reported by frontend engineers.

Developer Clarifications

Frequently Asked Questions

Engineering answers regarding token footprint, model compatibility, and design system interoperability.

Does Turtleneck work with Tailwind CSS, shadcn/ui, or custom CSS? +
Yes. Turtleneck is framework-agnostic. It does not replace your styling layer; it dictates the judgment rules your agent applies when writing Tailwind classes, CSS Modules, or shadcn component wrappers. For example, it prevents arbitrary utility chains like p-[33px] text-[#777] and ensures semantic tokens, accessible states, and correct line heights are used.
How many prompt tokens does the skill consume during agent execution? +
The entire Turtleneck judgment rubric is compiled into an ultra-condensed prompt specification of ~480 tokens. When using Claude Code or Cursor MCP tools, it selectively activates only when the agent is planning or modifying UI files, yielding virtually zero token waste on backend or logic code.
What models are supported? +
Turtleneck has been benchmarked and calibrated against Claude 3.5 Sonnet, Claude 3.7 Sonnet, GPT-4o, and DeepSeek-V3. Because the heuristics are structured as deterministic constraints rather than subjective advice, any frontier model follows the rubrics with high adherence.
How does it enforce the WCAG 2.2 AA contrast rules? +
Turtleneck injects contrast invariance into the agent's spatial token map. Before emitting any color combination, the agent is instructed to verify relative luminance according to the standard formula: (L1 + 0.05) / (L2 + 0.05) >= 4.5:1. If a muted text color fails, it is automatically shifted up the luminance scale.
Is Turtleneck open source? +
Yes, the core skill specification, MCP server, and evaluation harness are licensed under the MIT License. You can inspect the complete rule set, modify guidelines for your proprietary design tokens, and contribute custom heuristics on GitHub.
