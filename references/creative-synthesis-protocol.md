# Creative Synthesis Protocol: Originality & Fusion

Explicit rules to prevent 1:1 cloning of reference websites and ensure agents generate original, bespoke designs with authentic craft.

---

## 1. The Anti-Cloning Rule (Tri-Source Fusion)

Never copy a single reference site. To create an original visual identity, fuse 3 orthogonal sources:

```
[Texture/Tone from Source A]  +  [Interaction Model from Source B]  +  [Layout Architecture from Source C]
                                        │
                                        ▼
                         Bespoke, Original Product UI
```

* **Source A (Atmosphere / Materials)**: Real-world physical tactile textures (vintage audio synthesizer, Japanese stationery, risograph print, mechanical Swiss horology).
* **Source B (Interaction Model)**: Domain-appropriate tactile mechanics (patch bay pins, rotary sliders, timeline scrubbers, physical rocker switches).
* **Source C (Information Architecture)**: Real software functional requirements (data feeds, status monitors, inspection drawers).

---

## 2. Metaphor Transposition (Never Steal the Metaphor)

* If reference uses a "Ladder", do **NOT** use a ladder. Use an architectural cross-section, a patch routing bay, a step sequencer, or an altitude altimeter.
* If reference uses a "Hand-drawn avatar", do **NOT** copy hand-drawn avatars. Use an original geometric crest, schematic icon, or typographic monogram.
* If reference uses a specific motto, write **original, domain-accurate voice**.

---

## 3. The Original Craft Checklist

Before delivering a design, verify:
* [ ] Does this look like an exact clone of any single website? *(If yes, fail and mutate).*
* [ ] Is the color palette bespoke with calibrated contrast?
* [ ] Does the interactive mechanic reflect the actual problem being solved?
* [ ] Is the microcopy original, direct, and free of both AI-slop buzzwords and cloned clichés?
