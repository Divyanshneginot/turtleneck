## the_ladder

Stop at the first rung that holds.

  • 01 Does this need to exist?Speculative need = skip it. (YAGNI)
  • 02 Already in this codebase?Reuse the helper or token already here.
  • 03 Warm espresso over dead gray?Use earthy warmth (#0e0d0b + #d8d3c5).
  • 04 Native platform covers it?<input type="date"> over a 500KB picker library.
  • 05 Can it be one line?Make it one line.
  • 06 Only then:the minimum code that works.
