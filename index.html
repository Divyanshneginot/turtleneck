The difference between prompt whispering and deterministic engineering.

Kills Stateless Amnesia at the Root

LLMs have no durable memory between chats. Every session defaults to median internet web training: purple gradients, dark bento boxes, and unconstrained containers. You waste tokens re-prompting font stacks, border radii, and density preferences every day.

Turtleneck turns taste into an accumulated rejection ledger in .turtleneck/taste-profile.json. Reject a trope once, and the compiler injects your exact aesthetic DNA into every agent turn.

The 4-State Production Guarantee

Dribbble prototypes only render the happy path. Turtleneck blocks task completion until Empty, Loading skeleton, and Error recovery states are verified in the markup.

Zero-Dependency Python Gates

No prompt begging. Five deterministic gates run in local CI, mechanically asserting contrast maths, focus rings, compositor motion, and layout bounds before code is merged.

Mechanical Verification in CI

All five gates run with Python standard library alone. Zero heavy dependencies.

GATE 01
check_frontmatter.py
Asserts trigger-only discovery format and bounded description character count.
GATE 02
check_consistency.py
Verifies byte-identical pipeline parity across all 6 agent rule configurations.
GATE 03
check_contrast.py
Mathematically checks all 46 declared color pairs against WCAG 2.2 AA.
GATE 04
check_examples.py
Guarantees focus-visible outlines, reduced-motion blocks, and accessible names.
GATE 05
check_stress.py
Enforces anti-slop rules, 4-state completeness, and mobile layout containment.
