01 // Interaction Physics

5-State completeness.
Every control tactile and complete.

Every interactive control declares default, hover, active (scale 0.97), focus-visible (2px solid with 2px offset), and disabled/loading states. Test the physical response engine below.

Interact with the button below via mouse, trackpad, or keyboard (Tab & Enter) to watch the state matrix resolve in real time.

State: Interactive
1. DEFAULT (Resting state, 4.5:1 text, clear bounds) LIT
2. HOVER (Elevation / border tint, compositor ease) OFF
3. ACTIVE (Physical compression scale 0.97, sound) OFF
4. FOCUS-VISIBLE (2px solid, 2px offset, ≥3:1 ring) OFF
5. DISABLED / LOADING (Preserved layout, clear cues) OFF

03 // Archetype Taxonomy

One intelligence system.
Five distinct design personalities.

Turtleneck doesn't force a single aesthetic. It selects the exact interaction archetype for your product domain — from dark obsidian telemetry to brutalist monochrome.

Starlight Obsidian

Developer Tools • Telemetry

Dark obsidian elevation, razor-sharp 1px inner borders, and high-density monospace data badges.

Corporate Clean

FinTech • Enterprise SaaS

High-trust light surfaces, crisp slate borders, and conservative, legible typographic cadence.

Warm Editorial

Documentation • Longform

Warm textured paper tone, classic serif typography, and generous, relaxed reading line heights.

Modern Fluid

Creative Tools • Next-Gen

Deep dark cyan depth, subtle luminescence, and fluid, responsive interactive micro-surfaces.

1-Bit Minimal

Hacker • CLI Terminals

Pure stark monochrome contrast, 0px border radius, and strict monospace command layout.

04 // Autonomous Execution Flow

The Canonical 4-Phase Pipeline

Turtleneck doesn't just jump into styling. It executes a rigorous, multi-phase product design decision sequence before writing the first line of UI.

PHASE 01

Workspace Analysis

Audits existing repo conventions, token systems, color palettes, and component libraries to guarantee seamless integration.

PHASE 02

Requirements Interview

Aligns on user JTBD, critical state boundaries, error scenarios, and core operational workflows with minimal ceremony.

PHASE 03

Blueprint Alignment

Selects one of the 5 archetypes, establishes the 8pt spatial grid, maps the 5-state matrix, and validates contrast pairs.

PHASE 04

Production Build

Emits production-ready, accessible UI code with frequency-gated interaction timing, tactile feedback, and verified WCAG 2.2 AA compliance.

Canonical Pipeline Protocol
1. Workspace Analysis ──► 2. Requirements Interview ──► 3. Blueprint Alignment ──► 4. Production Build
