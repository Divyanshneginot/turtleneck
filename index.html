The Three Unsolved Frontiers

Why other UI skills fail at production software, and how Turtleneck's dual-engine harness solves it.

01 / PERSISTENCE

Kills "Groundhog Day"

Every other skill resets to default in every new chat. You waste tokens re-prompting font stacks, border radii, and density preferences forever. Turtleneck's Taste Ledger stores rejections permanently in your repo.

02 / PRODUCTION RIGOR

The 4-State Guarantee

AI models generate fragile happy-path Dribbble prototypes that crash when data is empty or text wraps. Turtleneck enforces Empty, Loading skeleton, and Error recovery states before marking tasks complete.

03 / VERIFICATION

Zero Prompt Whispering

Begging a token predictor to "have good taste" does not work. Turtleneck uses five zero-dependency Python gates that mechanically assert contrast, focus rings, compositor motion, and layout bounds in CI.

Proof Over Promises

Five automated verification gates run locally and on GitHub Actions with Python standard library alone.

GATE 01
check_frontmatter.py
Asserts trigger-only discovery format and bounded description length.
GATE 02
check_consistency.py
Ensures byte-identical pipeline parity across all 6 agent rules with zero drift.
GATE 03
check_contrast.py
Mathematically verifies all 46 declared color pairs meet strict WCAG 2.2 AA.
GATE 04
check_examples.py
Guarantees focus-visible outlines, reduced-motion fallbacks, and a11y names.
GATE 05
check_stress.py
Enforces anti-slop rules, 4-state completeness, and layout blowout safety.
