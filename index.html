the_discipline

Decide, then make. Do not decorate an undefined product.

  1. Inspect the reality. Scan local framework, component conventions, viewport, and token sources before writing code.
  2. Choose archetype from the job. Compare/monitor = dense table. Consequential choice = guided recommender. Create = template chooser. Never pick dark mode as an unthinking fashion default.
  3. Generate options before committing. On greenfield surfaces, pitch 2–3 structurally distinct layouts with trade-offs.
  4. Design the whole state machine. Default, hover, active (0.98 scale), focus-visible (2px ring), disabled, loading, empty, and error retry.
  5. Purposeful dynamic UI. Selection updates a real preview. Validation appears at the field. Zero animation that exists purely as decoration.
  6. Prove, don't promise. 86 automated test gates verify WCAG 2.2 AA math, prefers-reduced-motion, and compositor-only transitions.

adaptive_ceremony

Pick the least ceremony the brief earns.

// A full interview on a two-minute style fix is a protocol violation.

fastest

direct

Tiny unambiguous change, one component, or a style fix. Skip interview. Implement complete 5 states. Emit 4-line completion report.

standard

fast_path

Scope, stack, or outcome are already known. State inferred constraints in 1 preflight line. Select 1 pattern and 1 fallback. Build.

greenfield

discovery

Vague or high-stakes surface. Run compact design brief. Present 2–3 meaningfully distinct architectural options with trade-offs.
