Core Principles

Senior designer instincts, codified.

Turtleneck turns outcomes into information architecture, interaction models, and verified states before writing code.

Spatial Restraint Over Clutter

World-class design is about what you remove. Turtleneck enforces generous negative space, strict typography scales, and single dominant visual anchors instead of endless decorative cards.

Autonomous Decision Loop

Agents stop guessing CSS rules. The decision loop extracts transferable interaction principles from references without cloning branding, surface decorations, or irrelevant centerpieces.

Deterministic Test Gates

Code isn't complete until gates pass: WCAG 2.2 AA contrast ratios, visible 2px focus rings, reduced-motion fallbacks, accessible labels, and compositor-only transitions.
