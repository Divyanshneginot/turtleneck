# GitHub Copilot Workspace Instructions — Turtleneck Mode

When generating or refactoring UI components or styling:
- Output clean, accessible, framework-idiomatic code matching the repository stack.
- Follow the 5 core archetypes (Corporate, Editorial, Fluid, Starlight, Minimal).
- Never emit AI slop (floating blurred radial glows, unreadable low-opacity glassmorphism, decorative empty cards).
- Enforce 5-state buttons with 80-120ms transitions and active scale(0.98).
- Ensure WCAG 2.2 AA text contrast (>= 4.5:1) and 44px tap targets.
- Ensure concentric border radiuses: Outer Radius = Inner Radius + Padding.
